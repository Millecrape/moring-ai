# morning-ai

やること決めるAI

## 概要

朝の限られた時間で「今日は何をやろう？」と考える時間を減らし、
AIに今日やることを1つ提案してもらうアプリです。

ユーザーは提案されたことを「やる／やらない」で選択し、
実行した結果と満足度を記録します。

## 主な機能

- AIが今日やることを1つ提案
- 提案に対して「やる／やらない」を選択
- 実行結果を記録
- 満足度を記録
- 過去の実行履歴を保存

## 使用技術

- Python
- Streamlit
- Gemini API
- SQLite
- GitHub

## 開発方針

まずは必要最小限の機能で動くものを作り、
実際に使いながら改善していきます。
